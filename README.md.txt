# 🔐 Phishing Awareness Training

A cybersecurity awareness project developed as part of the **CodeAlpha Cyber Security Internship – Task 2**.

---

## 📌 Project Overview

Phishing is a social-engineering technique in which attackers attempt to deceive users into revealing sensitive information or performing unsafe actions.

This project is designed to educate users about phishing attacks and help them recognize suspicious emails, messages, websites, and social-engineering techniques.

---

## 🎯 Objectives

* Understand the basics of phishing.
* Learn how common phishing attacks work.
* Identify suspicious emails and messages.
* Recognize common signs of fake websites.
* Understand social-engineering techniques.
* Learn safe practices for avoiding phishing attacks.
* Test phishing awareness through an interactive quiz.

## 🚩 Common Warning Signs

Users should be cautious when they encounter:

* Unexpected urgent requests
* Suspicious sender addresses
* Unusual links or attachments
* Requests for passwords or OTPs
* Threatening language
* Unexpected payment requests
* Suspicious or misleading domains

---

## 🛡️ Safety Recommendations

* Verify the sender before responding.
* Inspect links before opening them.
* Never share passwords or OTPs.
* Enable Multi-Factor Authentication (MFA).
* Keep software and browsers updated.
* Access important services through official websites or applications.
* Report suspicious messages through appropriate channels.
